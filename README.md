# 📝 Lista de Tarefas (To-Do List)

> Aplicação web simples e objetiva para criar, organizar e gerenciar suas tarefas do dia a dia.

---

## 📌 Sobre o Projeto

A **Lista de Tarefas** foi desenvolvida para praticar a construção de uma aplicação web interativa utilizando **JavaScript nativo**. O projeto permite ao usuário adicionar novas tarefas, visualizar a lista de itens cadastrados e remover tarefas concluídas.

O foco principal deste desenvolvimento foi consolidar os fundamentos da web: manipulação do DOM (Document Object Model), escuta de eventos, gerenciamento de formulários e atualização dinâmica do conteúdo sem recarregar a página.

---

## ✨ Funcionalidades

- **Registrar Tarefas:** Campo de entrada para digitação e adição de novos itens.
- **Listagem Dinâmica:** Exibição imediata das tarefas cadastradas na tela.
- **Excluir Tarefas:** Botão dedicado para remover tarefas individualmente.
- **Interface Limpa:** Visual minimalista focado na usabilidade e facilidade de navegação.

---

## 🛠️ Tecnologias Utilizadas

Para este projeto, foram utilizadas as seguintes tecnologias:

- **HTML5:** Estruturação semântica dos elementos e formulário.
- **CSS3:** Estilização dos componentes, botões e alinhamento do layout.
- **JavaScript (Vanilla JS):** Lógica da aplicação, captura de eventos e manipulação dinâmica dos elementos do DOM.

## 🚀 Como Executar o Projeto

Como é um projeto web estático, você pode executá-lo diretamente no navegador.

### Passos:

```bash
# 1. Clone este repositório
$ git clone [https://github.com/gutoskt/projeto_lista_de_tarefa.git](https://github.com/gutoskt/projeto_lista_de_tarefa.git)

# 2. Acesse a pasta do projeto
$ cd projeto_lista_de_tarefa

# 3. Abra o arquivo index.html no seu navegador favorito

```
Se estiver usando o **VS Code**, clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.
